# Business Expansion Strategy: Data Analysis & Visualization

## 📌 Project Overview
This project aims to analyze international product sales data to identify key market trends, customer purchasing behaviors, and potential areas for business expansion. By processing raw databases and transforming them into interactive dashboards, this project provides data-driven insights to support strategic business decisions.

## 🛠️ Tech Stack & Tools Used
* **Database Management:** SQL Server
* **ETL (Extract, Transform, Load):** Talend Open Studio
* **Data Visualization:** Microsoft Power BI

## ⚙️ Workflow & Methodology
1. **Data Extraction & Cleaning:** Utilized **Talend Open Studio** to streamline the ETL process, ensuring data accuracy and removing inconsistencies from the raw dataset.
2. **Data Modeling & Querying:** Managed the structured data in **SQL Server**, writing complex queries to aggregate sales metrics, filter regional performances, and prepare the dataset for visualization.
3. **Dashboard Creation:** Imported the cleaned data into **Power BI** to build interactive and dynamic dashboards. 

## 📊 Key Business Insights
* Compared international business models to evaluate performance across different regions.
* Identified top-performing product categories and seasonal sales trends.
* Created actionable reports to guide stakeholders in targeted business expansion.
